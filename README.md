# young-man-two
The discussion between the 2nd young man with Buddha the Lord
# ติสสเมตเตยยมาณพปุจฉา : สายธารแห่งความสำรวมระวัง
**จาก โสฬสปัญหา ปารายนวรรค สุตตนิบาต ขุททกนิกาย พระสุตตันตปิฎก**

เมื่อประกายแห่งปัญญาจากคำถามของอชิตมาณพยังคงทอแสงระเรื่ออยู่ ณ ปาสาณเจดีย์ มาณพคนที่ ๒ นามว่า **"ท่านติสสเมตเตยยะ"** ผู้สำรวมระวังและเปี่ยมด้วยความเคารพ ก็ก้าวออกไปเบื้องหน้าพระพักตร์ นี่คือบทสนทนาว่าด้วย "ความสันโดษ" และ "การก้าวพ้นความหวั่นไหว" ในโลกที่เต็มไปด้วยสิ่งเร้า

---

## ๑. ผู้สันโดษและไร้ความหวั่นไหว
> **ติสสเมตเตยยมาณพ:** "ใครในโลกนี้ เป็นผู้สันโดษ (อิ่มเอมใจในปัจจุบัน)? ความหวั่นไหวไม่มีแก่ใคร? ใครรู้ส่วนสุดทั้งสองด้วยปัญญาแล้ว ไม่ติดอยู่ในท่ามกลาง? ใครคือมหาบุรุษ? และใครในโลกนี้ก้าวล่วงตัณหาเครื่องร้อยรัด (ตัณหาวิสัตติกา) ได้?"
> 
> **พระพุทธเจ้า:** "ภิกษุผู้ประพฤติพรหมจรรย์ ปราศจากความกำหนัดในกามทั้งหลาย มีสติระลึกได้ทุกเมื่อ รู้แจ้งธรรมแล้วดับกิเลสได้ ความหวั่นไหวย่อมไม่มีแก่ภิกษุนั้น"

**อรรถาธิบาย:** 
ในยุคที่ผู้คนหิวกระหายความสำเร็จและวัตถุ (กาม) ความหวั่นไหวและวิตกกังวลจึงกลายเป็นโรคระบาดทางวิญญาณ "ความสันโดษ" ในที่นี้ไม่ใช่ความเกียจคร้าน แต่คือการ "อิ่มเอมใจในปัจจุบันขณะ" ผู้ที่ก้าวล่วงความกำหนัดยินดีได้ด้วยสติ จะมีสภาวะจิตที่นิ่งสนิท (Zero-agitation) เปรียบดุจน้ำลึกที่สงบไร้ระลอกคลื่น 

---

## ๒. มหาบุรุษผู้ข้ามพ้นส่วนสุดทั้งสอง
> **พระพุทธเจ้า (ตรัสต่อ):** "ภิกษุนั้นรู้ส่วนสุดทั้งสอง (เช่น อดีตและอนาคต หรือ อัตตกิลมถานุโยคและกามสุขัลลิกานุโยค) ด้วยปัญญาแล้ว ไม่ติดอยู่ในท่ามกลาง เรากล่าวว่าภิกษุนั้นแลเป็น 'มหาบุรุษ' ภิกษุนั้นแลก้าวล่วงตัณหาเครื่องร้อยรัดในโลกนี้ได้แล้ว"

**อรรถาธิบาย:** 
มหาบุรุษในนิยามของพระพุทธศาสนา ไม่ใช่ผู้มีอำนาจล้นฟ้า แต่คือผู้มีปัญญาเฉียบแหลมที่มองเห็นความสุดโต่งของโลก (ส่วนสุดทั้งสอง) แล้วเลือกเดินบน "มัชฌิมาปฏิปทา" (ทางสายกลาง) ไม่ติดกับดักของอดีตที่ผ่านไปแล้ว ไม่วิตกถึงอนาคตที่ยังมาไม่ถึง และไม่ยึดติดแม้แต่ในปัจจุบัน (ไม่ติดในท่ามกลาง) นี่คือสถาปัตยกรรมแห่งการปลดแอกจิตใจอย่างแท้จริง

---
